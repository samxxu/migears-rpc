# P2-2 — Internal errors (code -32603) include the exception's short class name …

## Finding / 问题

- EN: Internal errors (code -32603) include the exception's short class name in the data field (via "class": "FooException"), leaking implementation details to the client. A production API should not expose internal exception class names.

- Verification / 验证: static / 仅静态推断

What it forks on: what a JSON-RPC error object discloses over the wire is a behaviour change — dropping `data`, or replacing the class name with a generic marker, changes the response body every client receives. Nothing was changed this pass.
